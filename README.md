# NetMotion

NetMotion is a complete FastAPI and JavaScript cellular-network simulation comparing conventional signal-threshold handover with a mobility-aware weighted handover engine.

All signal strengths, delays, congestion values, throughput estimates, and handover events are explicitly generated by the included illustrative simulation model. They are not measurements from a real telecom network.

## Run

From the project directory:

```powershell
py -m pip install -r requirements.txt
py run.py
```

Open `http://127.0.0.1:8000`.

## Features

- Real-time user movement and tower coverage visualization
- Conventional and mobility-aware handover engines
- Configurable tower capacity, threshold, stability margin, speed, and weights
- Normal, congestion, high-speed, tower-failure, and combined scenarios
- Calculated handover, delay, throughput, interruption, utilization, and success metrics
- SQLite experiment history
- CSV and PDF exports
- WebSocket state updates
